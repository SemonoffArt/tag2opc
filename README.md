# 🏭 tag2opc

**Конвертер списка тегов из SCADA FLS ECS7 в конфигурацию устройства Siemens PLC (.sdv) для MasterOPC**

## 📖 Описание

**tag2opc** — утилита командной строки, автоматизирующая настройку MasterOPC. Инструмент преобразует список тегов из SCADA FLS ECS7 в готовый файл конфигурации (.sdv) для OPC сервера.

В результате работы создаётся файл `siemens_plc_opc.sdv`, который после импорта через меню MasterOPC → «Импорт устройства» добавляет в конфигурацию сервера ПЛК с настроенными тегами.

Решение ориентировано на специалистов АСУ ТП: оно избавляет от рутинного ручного ввода тегов и минимизирует риск ошибок при конфигурировании сервера.

## 📄 Форматы данных

### 📝 Файл группировки `tags_list.txt`

Текстовый файл, определяющий принадлежность тегов к группам. Группы обозначаются заголовками `Group:имя_группы:`.

**Синтаксис:**
```txt
Group:имя_группы:
tag1
tag2

Group:другая_группа:
tag3
tag4
```

**Пример:**
```txt
Group:flot:
050AG280M01_I01
050AG281M01_I01
050SF280U01_SP

Group:sorb:
080MC480N01P01
080TN450N01F01
```

> 💡 **Совет:** Пустые строки игнорируются. Теги, не указанные в файле группировки, не будут добавлены в SDV-файл.

---

### 🏷️ Файл тегов `tags.json`

База данных тегов в формате JSON. Содержит полную информацию о каждом теге: имя, описание, PLC-адрес, тип данных, единицы измерения.

**Структура тега:**
```json
{
    "Id": 1407,
    "Tag": "_920_OUTDOOR_TEMP",
    "Groups": "992CD100G04",
    "DescEng": "Outdoor temp",
    "DescRus": "Уличная температура",
    "PLC": {
        "PLCNo": "992",
        "Input": {
            "Type": "Float",
            "Block": 9,
            "Word": 88
        }
    },
    "PLC_INP": "%DB9.DBD88",
    "EngUnitId": "°C",
    "Constant1": 1.0
}
```

**Описание полей:**
| Поле | Описание |
|------|----------|
| `Id` | Уникальный идентификатор тега |
| `Tag` | Имя тега (используется в SDV) |
| `DescEng` / `DescRus` | Описание на английском/русском |
| `PLC.Input.Type` | Тип данных (`Float`, `16 Bit`, `32 Bit`, `Bool`) |
| `PLC.Input.Block` | Номер блока данных DB |
| `PLC.Input.Word` | Адрес байта в блоке |
| `EngUnitId` | Единица измерения (°C, бар, м³/ч) |
| `Constant1` | Коэффициент масштабирования |

---

### 🔧 Выходной файл `.sdv`

Конфигурационный файл устройства в формате JSON с табуляцией как разделителем. Кодировка: **cp1251** (Windows-1251).

**Иерархическая структура:**
```
Device (корневой узел)
└── Group (группа тегов)
    └── Teg (тег с параметрами)
```

> ⚠️ **Важно:** SDV-файл использует нестандартный JSON с табуляцией. После сохранения ключи `node_xx*` нормализуются в `node`.
